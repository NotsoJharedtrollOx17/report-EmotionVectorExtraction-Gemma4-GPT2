\subsection*{Code and Data Availability}

The implementation, generated artifacts, figure files, and a simplified results summary for this replication are available in the 
accompanying GitHub repository:

\url{https://github.com/NotsoJharedtrollOx17/EmotionVectorExtraction-Gemma4-GPT2}

The repository also documents the analysis pipeline, saved outputs, and replication-specific implementation details needed to 
interpret the results reported here.

The revised report source is identified by release v2.1.3 in the companion repository:

\href{https://github.com/NotsoJharedtrollOx17/report-EmotionVectorExtraction-Gemma4-GPT2/releases/tag/v2.1.3}{\texttt{report-EmotionVectorExtraction-Gemma4-GPT2 v2.1.3}}

The matching PDF is distributed with that release and with code/data release v2.1.3. The four notebooks preserve historical
outputs and execution state; they are not evidence of a clean end-to-end rerun from the current corpus. In particular, the saved
Gemma 4 E2B nine-emotion notebook contains a \texttt{NameError} for undefined \texttt{numberEmotions} in a heatmap-saving cell.
This revision preserves that record and does not repair or rerun the experiment.
